# Experiments

Proposals live in `candidates/` as one file each, named `EXP-NNN_<slug>.md`, built from
[experiment_template.md](experiment_template.md). When an experiment starts running, add a dated
row to its results log and a line in [../research/22_RESEARCH_LOG.md](../research/22_RESEARCH_LOG.md).
The prioritised list is [../research/16_EXPERIMENT_BACKLOG.md](../research/16_EXPERIMENT_BACKLOG.md).

Rules:
- Every experiment states its zero-purchase status up front. If it needs hardware, it names the
  exact device and the exact measurement that cannot be made without it.
- Recording of humans is explicitly initiated, consented, indicated and deletable
  ([../research/18_PRIVACY_SAFETY_AND_ETHICS.md](../research/18_PRIVACY_SAFETY_AND_ETHICS.md)).
- Negative results are results. Record them.
- Code for an experiment goes in a subfolder next to its proposal (`candidates/EXP-NNN_<slug>/`).
